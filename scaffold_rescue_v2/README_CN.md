# 统一几何干预入口 v2

保留已成功的 A、B、AB；补齐固定片段碰撞的干预 C。
运行一次，覆盖本批全部 8 个失败样本，输出所有候选的结果并保留合格版本。

## 为什么之前漏了5个

上一版按“生成部分有碰撞”选样本，排除了 BACE。
BACE 碰撞发生在固定片段 Cl 与水之间；只移动生成部分，不能改变这一对原子的距离。
把 Cl 恢复到参考坐标也不够，因为参考坐标本身已经有碰撞。
它们仍然是原评价下的失败，不能直接算作已经解决。

## 新版具体做什么

| 分支 | 做什么 | 是否允许固定片段坐标自由调整 |
|---|---|---|
| A | 恢复固定片段原始坐标 | 只恢复，不优化 |
| B | 优化生成部分的几何与环境距离 | 否 |
| AB | 先恢复固定片段，再优化生成部分 | 只恢复，不优化 |
| C | 固定部分和生成部分一起做有界坐标优化 | 是 |

C 已包含两部分联合优化；不再额外穷举冗余排列组合。
所有分支使用原评价程序。原子类型、键、形式电荷、蛋白和水不变。
评价仍要求原化学有效、连通、固定片段化学和原生子结构检查，以及整分子全部 PoseBusters 检查通过。
Murcko 变化和固定片段位移继续作描述，不擅自新增通过阈值。

**C 明确放松“固定原子坐标不动”的条件。** 因为你的现有评价没有固定坐标位移的硬阈值，
它可以作为“原评价通过”的修复分支；但必须单列，不能写成“固定姿势完全不变仍成功”。
每个可移动原子每轴最大变化 2 Å，每次最多 80 次迭代、200 次目标函数调用。
坐标位移和相对参考的固定片段偏移均记录。这里没有声称保持原结合姿势或生物活性。

## 如何避免反复改一个样本

1. 根据失败检查项选择支持范围，不按 BACE/PTP1B 名称或某个水编号筛选。
2. 对全部支持的失败样本及同输入的通过样本，执行同一套预定分支和对照。
3. 每个主分支配 3 个逐原子位移大小匹配的随机方向对照；另做 3 个普通 UFF 优化对照。
4. 全部运行后统一报告，保留所有成功分支。多个分支独立通过就都记录。
5. 原本通过的样本保留原始版本；原本失败的样本按 A→B→AB→C 固定优先级选一个合格版本。
6. 没有分支通过就记录“未修复”；未实现的失败类型记录“未覆盖”。本轮停止，不自动调参数或加样本。

这批共 20 次基线评价 + 10 个样本 × 19 个干预/对照 = **最多210次完整评价**。
其中 10 个样本是 BACE 5 个、PTP1B 5 个；包含全部8个失败和2个通过对照。
不是重新生成210个分子，不调用生成网络或加载模型权重。

## 能覆盖什么，不能覆盖什么

同一套几何干预可尝试水/蛋白/辅因子距离冲突、体积重叠、键长/键角、内部碰撞、平面性与内部能量问题。
“有对应干预”不等于保证修复。当前实证仍来自这批环境碰撞样本。
价态、断连、原子或键类型错误等离散化学问题，以及未实现的检查项，会明确报告未覆盖。
未来新增此类方法，只扩充干预库和对应测试，保留统一评价、对照、选择及停止规则。
本轮没有验证具体网络层；换模型仍需适配记录和解码接口，尚未证明跨模型泛化。

## 结果怎么看

- `summary.json`：原来多少失败、A/B/AB 修复多少、允许固定坐标移动后修复多少、仍未解决多少。
- `selected_results.csv`：每个样本选了哪个版本，以及所有通过的主分支。
- `selected_outputs/`：程序完整结束后导出的合格 SDF，原本通过的样本保留原始版本。
- `candidate_results.csv`：A/B/AB/C 各自结果；组合通过与单独通过分开记录。
- `paired_summary.csv`：全部分支与对照的原评价结果。
- `coverage.json`：每个样本是否覆盖及理由。
- `branch_errors.json`：未完成的分支，不能把程序错误当分子失败或原因被否定。
- `status.json`：流程是否结束、全部分支是否均完成。

“选出成功版本”的统计是固定干预组合的修复覆盖率，不能当成原模型直接生成成功率。
