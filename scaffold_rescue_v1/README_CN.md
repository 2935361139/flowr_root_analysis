# 有限干预实验：从现有 20 条记录继续

当前阶段：候选异常已定位，下一步验证干预能否让整个分子通过原评价。
这是终态坐标修复实验；不调用生成网络，不验证隐藏层机制，不重新生成样本。

## 已有证据

- 本批 20 个：12 个通过，8 个 PoseBusters 失败；化学有效、连通、固定片段化学与原生子结构检查均通过。
- BACE 的 5 个：固定 Cl 与水的冲突在参考输入已存在，采样记录从开始就存在。本轮只复核，保留失败标签，不继续向下追查。
- PTP1B seed1001：固定 O 的碰撞在采样器最后输出帧 100 出现；网络预测中从调用 8 开始持续出现。两种编号不能混用。
- PTP1B seed1001、1004、1005：生成部分也有碰撞。已有具体原子和时间记录；部分早期原子类型变化，不能一概宣称找到了精确首次出错步。
- 没有定位到具体隐藏网络层。以上是候选异常证据，干预成功与否尚未确认。

## 本轮只做什么

先按原代码重评全部 20 个基线；任一基线标签、记录或评价源码不一致，立即停止并打包错误。
然后对 PTP1B 的全部 5 个样本做实验：3 个失败，2 个通过作对照。
选择依据是已记录的生成部分碰撞，不依据哪种干预容易成功。

| 分支 | 做什么 |
|---|---|
| A | 只把固定片段坐标恢复为记录中的原始坐标 |
| B | 固定片段保持原输出坐标，只调整生成部分；同时约束分子内部几何、环境碰撞和位移 |
| AB | 先恢复固定片段，再执行 B |
| UFF_only / A_UFF_only | 去掉环境排斥项的几何优化对照，检查普通几何优化是否已足够 |
| 每个候选的 3 个随机对照 | 逐原子位移大小相同，方向改为随机正交方向；AB 的随机对照保留 A，只随机化生成部分 |

B 使用当前 PoseBusters 对蛋白、水、辅因子的环境选择和原子半径；不只针对一颗指定的水。
固定原子不参与 B 的移动。原子类型、键、形式电荷、蛋白和水均保持原样。
UFF 内部辅助氢会参与优化，但不写回输出；原评价程序重新加氢。

总计最多 20 次基线评价 + 5 × 14 次干预/对照评价 = 90 次完整评价。
每个优化最多 80 次迭代、200 次目标函数调用，坐标每个轴最多移动 2 Å。
排斥强度 500、位移约束强度 2、干预余量 0.1 Å 在运行前固定；这些不是新的通过阈值。
达到预算即评价当前结果，记录是否收敛；不会继续调参数、加种子或追查更深网络层。

## 成功怎么记

成功必须同时满足原化学有效、连通、固定片段与子结构检查，以及全部原生 PoseBusters 检查。
仅修好一处碰撞、整体仍有失败，不算成功。Murcko 是否变化仍只作描述，不擅自增加失败标准。

- A 单独使原失败样本通过：A 记为有效干预原因。
- B 单独使原失败样本通过：B 记为有效干预原因。
- A、B 各自都能使其通过：两个都记。
- 只有 AB 通过：记为组合有效，不能写成 A、B 已各自验证。
- 全部不通过：记录本轮未找到有效干预原因，停止。
- 原本通过的样本只统计是否退化，不能记成“救回”。

这里“原因”采用你的操作性定义：能使失败转为通过的干预因素。
结果支持终态修复有效；即使成功，也不能单凭这一轮认定唯一上游根因或具体网络层。
随机/普通优化对照的结果一并报告，帮助判断修复是否具有特异性。

## 安装和运行

把 `scaffold_rescue_v1.zip` 解压到项目根目录，得到 `scaffold_rescue_v1/` 文件夹。
使用现有 `.venv`，不升级依赖，不运行旧的 fixed-only 干预包。

```bash
cd /home/ljl/projects/flowr_root
source .venv/bin/activate
python scaffold_rescue_v1/install_update.py --repo .
```

安装器会备份旧文件到 `archive/rescue_v1_backup_时间/`，然后只写入：

- `scaffold_study_v1/terminal_control.py`：替换旧干预入口。
- `scaffold_study_v1/geometry_intervention.py`：新增通用坐标干预函数。

保留现有生成、记录、诊断、定位和评价代码。现有定位更新包必须已经安装且运行成功。
本轮需要原项目中的完整 `.pt` 文件；此前提交的轻量审核包不能替代它们。

运行自检；两条都显示 `OK` 后继续：

```bash
python scaffold_rescue_v1/test_coordinate_control.py --repo .
python scaffold_rescue_v1/test_geometry_intervention.py
```

执行一次：

```bash
python scaffold_study_v1/terminal_control.py --repo .
```

输入为 `outputs/sh_restart_v1/`，包括 `runs/`、`quality/`、`diagnostics/`、`localization_v2/geometry/`。
脚本拒绝覆盖已有 `outputs/sh_restart_v1/rescue_v1/`。发生错误不要删目录重复跑。
无论正常结束还是捕获到错误，提交下面一个文件即可：

```text

```

包内 `status.json` 表明实验是否完成；`candidate_results.csv` 列出每个样本的有效候选/组合；
`paired_summary.csv` 列出全部评价结果；每个样本文件夹保留各分支 SDF、检查结果、位移和优化记录。
若因解释器无法启动等原因未生成 ZIP，提交终端完整报错。
