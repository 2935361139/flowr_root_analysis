# 下一步：统一的因果定位初筛

目标仍是固定片段条件下的 scaffold hopping：新骨架接入后，连接碳原本必须保留的化学结构为什么发生变化。

本次先检验 BACE ligand_idx=16、seed50 的 C2—N3 三键丢失。它不是终态碳超价：碳在改变其它连接后仍可化学有效，但固定片段已经不匹配。不能把这种失败和“分子必须恢复参考骨架”混为一谈。

## 已经得到什么证据

上传的 head_review(2).zip 完整通过：50 次真实回放、40 条相邻时刻得分分解、45 条对照分解。

call31→32 的三键相对单键得分下降 2.068865：

| 成键头输入组 | 对得分变化的分配值 |
|---|---:|
| 原子对表征 | −1.541665 |
| 两个原子的表征 | −0.529025 |
| 直接几何输入 | +0.002355 |
| 单独报告的数值差异 | −0.000529 |

这是一条指定路径上的局部数学分解，说明原子对和原子表征值得优先检验，不证明唯一根因。直接几何列小，也不能排除其它表征中编码的几何影响。

与九条固定片段保留轨迹相比，seed50 的原子表征也有明显得分差异，因此本轮同时检验原子对和原子表征。九条对照有其它 PoseBusters 问题，不能称为整体全部成功。

唯一数值敏感标记出现在对照 seed43 的 call31→32：实际变化只有约 0.000061，而数值差异约 0.001742。它不影响 seed50 上述较大的下降，但不能据此解读对照的极微变化方向。

## 本轮实验固定为 198 次

- 4 个调用：0、3、25、32，覆盖早期、短暂异常、新外接键冲突和持续改判。
- 4 个层边界：第 3、6、9、12 层。层编号从 1 开始，调用编号从 0 开始。
- 2 类表征：固定 C2、N3 的两个标量节点向量；C2→N3 和 N3→C2 的原子对向量。
- 3 条表征供体：seed42、43、44。预先选择现有记录中编号最早的三条固定片段保留轨迹，不按干预结果挑供体。
- 每个组合做一次供体替换、一次同等幅度的随机方向修改。
- 加上 4 次完整原始基线、2 次零修改对照：共 198 次。

每次只在一个调用、一个层边界修改一次，然后继续运行原生采样器直到终态。没有把之后保存的旧状态重新喂回，也没有强行把预测键改成三键。

供体与失败轨迹初始噪声不同；每次干预与其原始失败基线使用同一随机流。本轮能测试所指定替换的因果效果，不能把不同种子之间的全部差异归结为一个计算。

## 输出与判断

- `scan_results.csv`：每次干预的终态、指定键的类别、局部得分变化及实际修改幅度。
- `scan_map.png`：时间与层位置的化学终态结果图。3/3 表示三个供体的修改均取得该终态，不是三个独立失败样本成功。
- `trials/*/network_timeline.json`、`sampler_timeline.json`：修改后局部效果是否保持到最后。
- 每次的原始与默认修复解码 SDF，以及固定片段、价态、连通性、PoseBusters 等检查。
- 原生终态张量 `.pt` 留在你的输出目录，精简 ZIP 不包含这些较大的文件。

主要化学终态采用原始解码有效、连通、ROOT 固定片段匹配。原槽位的固定化学身份诊断同时报告，防止把匹配到另一组原子误解成指定连接已被恢复。PoseBusters、骨架变化分别报告，不把化学终态通过说成全部 scaffold hopping 指标通过。

分析时分别看：局部得分是否改变；最终固定片段是否恢复；是否制造超价、断连等新问题；供体替换是否优于同等幅度随机修改。

如果没有终态修复，也要检查局部影响随后是否被覆盖；不能从本轮失败直接断言这些表征没有因果作用。若有修复，说明该替换有因果影响，尚不证明该层最先产生错误或是唯一根因。

## 复用与范围

这是一个统一执行器加配置文件，循环逻辑中没有写死 BACE、seed50 或原子编号。复用了之前的原生回放框架和评价函数。

当前接口支持：同一 FLOWR.ROOT 版本、同一输入条件下，相同固定原子身份之间的表征替换；可换输入、时刻、层和固定原子对配置。它明确拒绝用同一编号跨种子对齐生成原子。固定—生成原子对或其他网络结构需要相应映射/接口适配。

本轮是四个层边界和四个时刻的粗扫描，不是全模型穷尽定位，也不是所有分子错误的自动诊断器。结论泛化需要在未参与当前探索的输入上检验，不能由 198 次同一失败案例的回放来证明。

Meltdown 第 3.2 节和附录 D 使用按层、时刻、内部位置进行激活替换的思路：<https://arxiv.org/html/2602.11130v2>。本轮迁移这一实验逻辑，采用适合分子模型的表征和终态标准，未照搬其点云指标或宣称复现其结果。
