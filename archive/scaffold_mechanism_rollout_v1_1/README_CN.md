## 你本次上传的结果是什么

`rollout_review.zip` 的 `status.json` 显示 `completed=false`、`completed_trials=0`、`planned_trials=150`。第一条 `seed_42_sham` 在调用52的非成键输出校验中中止；这条运行没有施加干预。它不是150次因果实验失败，也不是候选机制被推翻。

`error.txt` 把错误定位到 `native_adapter.compare_tree`：旧实现用 `set(a)` 和 `for k in a` 遍历映射。ROOT 的亲和力/对接分数输出含有 `TensorDict`；该容器的直接迭代针对批维度，不等于普通字典的键。原生源码 `flowr/models/pocket.py` 确实用无 batch_size 的 TensorDict 创建这些输出。

这次仅把该比较器改为显式调用 `.keys()`，仍检查所有字段、数值、形状、类型、有限值与原有容差。没有跳过辅助输出或放宽失败定义。运行入口只另外更新了版本号和默认输出目录。原来的方案、150条列表、候选特征、调用号、随机对照、模型和成功标准保持原样。

本地18项软件测试通过，包括7项新增的 TensorDict 回归测试。测试覆盖空/非空、带/不带批维度、嵌套映射、TensorDict 与已保存普通字典的互相比较；也覆盖真实 TensorDict 辅助输出下的原样回放、定向修改、随机对照及错误值拒绝。旧比较器在本地真实 TensorDict 上也会因直接迭代报错；本地0.15.3版本的异常文字与用户的版本不同，因此不声称完全复现了同一个异常文字。本地没有原始完整权重、CUDA或完整轨迹，不能声称150条真实ROOT实验已跑通。

## 这项研究查到哪里可以停

研究对象限定为：固定片段连接位点多成键、导致超价这一类失败。当前假设限定为：成键头入口的几何/边表征变化在指定时刻促进多余键，并可能影响最终连接结局。

已经有证据：局部替换这些特征能改变该次成键预测。尚缺：在完整生成中，定向干预相对于同幅度随机对照是否改变终态。目前的 donor 是同一轨迹前一时刻的特征，不是Meltdown的同一时刻健康/失败输入配对；这是借鉴其因果检验思路的本任务改编，不是原方法的完整复现。

Meltdown第6节明确将单位置干预称为可挽救失败的作用点，同时承认它未必是单独充分的致错原因，也不能排除分布式机制。因此本项目不以“解释全部权重为什么被训练成这样”或“排除一切其他原因”为终点。

本批次的停止规则：

- 程序错误：修复实验工具；不计为科学假设的成功或失败。
- 当步改变但终态不改善：报告“局部成键作用成立，单次该处干预不足以挽救终态”；停止这个预定单样本方案，不自动追加时刻、剂量、种子。
- 定向修改与随机修改都改善：报告缺少方向特异证据；不能称为已确认的特定机制。
- 定向修改表现出终态作用且优于已设对照：得到该输入条件下的机制证据，固定方法后转向独立分子输入检验，而不是无限向上游追查。

十个随机种子仍只对应一个输入，不能据此声称跨分子泛化。独立验证时按分子/骨架划分新输入，保留同一失败定义、映射与诊断规则，报告支持、反证、未能解释及正常样本副作用；不要逐样本重新编写“成功解释”。当前结果也不是DiffSHAPer式输入原子贡献。

文献依据：Meltdown §3.2–3.3、§6，https://arxiv.org/html/2602.11130v2 。本停止规则是本项目的研究设计，不是论文要求固定150次。

# 从当步成键作用到最终生成：一次固定批次的验证

## 本次已经得到的实际结果

上传的 `mechanism_review(1).zip` 完整完成：114/114 状态通过原始回放、只读观察及原生读出校验；55/55 窗口通过端点校验，共880种局部组合、1202条边级记录。全部55份分解已从压缩数组中的原生成键分数重算，与CSV完全一致。详见 `OBSERVED_RESULTS.json`。

PTP1B ligand 1、seed 42：在调用号51→52（从0编号）的持续超价起始窗口，固定氧槽位3与生成槽位11由“无键”变为“单键”。原先已有的另外两条单键保留，导致中性氧超价。该位点更早也出现过短暂异常；52不是整条轨迹首次出现异常，也尚未证明是最终失败的决定时刻。

| 在调用52的成键头入口做什么 | 当步位点超价 | 当步化学有效且连通 |
| --- | --- | --- |
| 保持当前真实特征 | 是 | 否 |
| 仅把几何特征取回调用51的值 | 消失 | 是 |
| 仅把边表征取回调用51的值 | 消失 | 是 |
| 同时取回几何和边表征 | 消失 | 是 |
| 仅取回固定节点表征 | 仍存在 | 否 |
| 仅取回生成节点表征 | 仍存在 | 否 |

多余边的“单键分数减无键分数”由 -0.374513 变为 +0.046017。分数变化中，几何贡献 +0.223328，边表征贡献 +0.280563，两类节点表征分别为 -0.053048、-0.030313。四项相加等于 +0.420530。这里是成键头局部作用分解，不是根因概率；也不能将几何特征贡献解释为“该样本的几何误差一定比所有成功样本大”。

全部14个异常出现窗口中：只取回几何可消除7个窗口的位点超价；只取回边表征也是7个；两者合用为10个。这些窗口来自已有轨迹，不是14个独立分子。早期中间预测本来就可能不连通，因此始终单列化学有效性、连通性及最终结果。不能把消除一个局部错误等同于完整 scaffold hopping 成功。

已经支持的结论：在上述真实生成状态附近，几何和边表征的变化推动了这条多余键的当步决策。尚未确认：上游哪些计算产生这些变化；一次定向修改是否改变最终失败；该机制是否跨输入成立。

## 固定一次比较哪些条件

程序从V2唯一的持续异常起始窗口确定调用、参考位点及输入，再通过真实映射找各次生成中的固定槽位。当前对应参考原子14、调用52、已有PTP1B输入的10个种子。

每个种子15条完整生成，共150条：

- 1条原样回放：全部网络调用及最终张量必须重现已有结果。
- 5条定向修改：几何、边表征、两者合用、固定节点、生成节点。
- 9条随机对照：几何、边表征、两者合用各3条；在相同特征范围内逐组匹配修改幅度，并改变方向。

全部10条原样回放先通过，才开始其余实验。每条都从同一个种子的原始初始状态完整回放；干预前必须重现原始输入和输出。在选定调用仅写一次成键头入口，随后使用原生采样器自由生成，不把后来的已保存状态塞回去。

随机对照使用独立局部随机源，不消费生成器的随机流；每个后续调用检查原生随机流保持配对。几何的两个方向拷贝保持对称；随机方向在每组内与定向变化正交，并匹配范数。浮点写入后记录实际幅度与夹角。过小、无信息的修改会明确标记，不能用来证明方向特异性。

这些替换操作是计算层面的实验：几何特征为距离平方和坐标点积的读出输入，并非直接移动分子坐标；节点特征替换限于指定边在成键头入口的拷贝。混合特征及随机特征不保证对应自然生成状态，这限制了因果解释的范围。

已有局部组合覆盖到的定向运行，还必须在实际完整生成中重现V2所记录的当步边分数。干预当步的非键输出保持不变。每条保存完整的位点化学时间线和最终分子，并分别评价不修复的原始解码与原运行的重建修复。

## 怎样判断结果

重点看 `rollout_results.csv` 和各条运行的 `network_timeline.json`：

| 结果 | 能支持什么 |
| --- | --- |
| 当步错误消失，后续又出现，最终仍失败 | 已证实局部作用，但一次修改不足以持续改变最终结果；时间线记录首次再出现调用 |
| 定向修改改变最终连接，随机对照没有同样效果 | 支持该路径在本条件下对最终连接有特异因果影响 |
| 定向与随机修改都有效 | 还不能把效果归因于所提出的特定方向 |
| 几何或边单独无效，合用有效 | 支持在本次干预定义下存在联合作用，需要报告组合结果 |
| 成功种子被修改后变差 | 表明干预有副作用，不能只报告失败样本的改善 |
| 全部校验通过，但目标修改未改变终态 | 如实报告该固定实验不支持“一次该位置修改足以修复终态”；不自动换时刻、加幅度或扩样本 |

最终分别报告原始分子的化学有效性、连通性、ROOT固定片段匹配、原槽位固定化学身份、PoseBusters以及骨架是否改变。`raw_connection_and_fixed_identity` 要求原始解码有效、连通、通过ROOT固定片段匹配，并保留原槽位固定化学身份；原来的ROOT组合指标仍单独保留。新骨架不需要恢复参考结构。只有连接化学改善、PoseBusters仍未通过时，不能宣称整体生成质量已合格。

150条实验只有一个分子输入；当前方案从已查看的数据选出，属于发现与机制检验阶段。程序可按同样记录格式、参考位点映射和配置复用，但跨分子泛化必须在未用于选择机制的新输入上另行验证。程序不输出“唯一根因”标签，也不输出DiffSHAPer式输入原子贡献。
